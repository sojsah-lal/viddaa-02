Privacy Policy

Last updated: 30 October 2026

What Vidda accesses

  • user.info.basic: the owner's TikTok open ID, used only to confirm which account is logged in.
  • video.upload: lets Vidda send its own generated videos to the owner's TikTok inbox as drafts.

What Vidda stores

Only a TikTok refresh token for the owner's account, kept as an encrypted GitHub Actions secret. Vidda does not store, sell or share any other TikTok data, and it does not collect data about other TikTok users or viewers.

How to remove access

The owner can revoke Vidda at any time in TikTok: Settings and privacy → Security → Apps and services. Deleting the GitHub secret removes the stored token.
